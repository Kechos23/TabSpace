# Changelog

## Initial public release

This repository starts from a reviewed product snapshot. The release tags share the clean initial source commit.

### TabSpace 0.18.4

- Local-first Spaces, Collections, tabs, Resources, formatted Notes and checklist Tasks.
- Manager, compact Chrome side panel and toolbar popup.
- Saved/Unsaved browsing, configurable startup recovery and Saved Space tab locking.
- Optional encrypted Nextcloud/WebDAV synchronization to a user-selected server.
- Optional Windows Drag Group integration and an independent automatic pinned manager.
- One extension download that keeps Chrome's normal new-tab page.

### Drag Group 0.1.21

- Standalone drag-to-group using native Chrome tab groups.
- Shared controller lifecycle with the integrated edition, independent settings and extension identity.
- Ready-only paired feedback at 16% overlap and 200 ms dwell; cancellation and bounded 30-second holds.
- Shared Windows helper and explicit origin/gesture validation.

### Shared helper installer 1.0.0

- Per-user Windows installation, runtime checks, repair/update and Windows Apps uninstall.
- Registration ownership checks, explicit replacement and rollback without closing Chrome.
- GPL-3.0-only source and distribution packages; bundled dependency notices.

See [known limitations](docs/KNOWN_LIMITATIONS.md) and [validation](docs/validation/README.md) for supported scope and remaining manual acceptance.
