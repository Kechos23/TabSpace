Drag Group

Grab an ungrouped tab by its title and slightly overlap another tab. Pause for 200 ms, then release when the matching tab outlines appear. Their colour follows your Windows accent colour.

This pinned controller identifies this Chrome window. Keep it open. Drag Group starts automatically in every normal window. Use the toolbar popup to pause or resume all windows. Ordinary fast reordering stays unchanged.

Starting automatically. Install the Windows helper first using the shared helper Setup.

    Supported gesture limits
    • Normal horizontal tab strips; all tabs must be visible. No incognito.
    • One unpinned, ungrouped source and target in the same window.
    • When Chrome moves a passed tab behind the dragged tab, it stops being a target. Matching outlines mark the dragged tab and the next eligible target. Overlap uses actual tab widths and preserves your original grab offset.
    • Escape, focus loss, ambiguous identity, changed tab membership, overflow and timeout cancel grouping.
    • Manual acceptance on other DPI/monitors/Chrome builds is still required. No Linux helper yet.
