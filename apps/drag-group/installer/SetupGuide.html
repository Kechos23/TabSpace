TABSPACE + DRAG GROUP

Your helper is installed.

The helper adds drag-to-group to Chrome. TabSpace's organizer and independent pinned manager work without it.

Connect your extension

  1. Open TabSpace → Settings → Drag Group, or the standalone Drag Group popup.
  2. Enable Drag Group and accept Chrome's helper permission if prompted.
  3. Wait for Ready. Keep the pinned manager/controller open.

Use one active Drag Group edition at a time. Both editions use this single helper installation. The installer does not install or enable a Chrome extension.

Try grouping

Drag one unpinned, ungrouped tab over another in the same Chrome window. Hold briefly until the paired outline appears, then release. Move back to cancel.

Update, repair or remove

Pause Drag Group first, or close Chrome completely. Run the downloaded Setup again to update or repair. To remove the helper, use Windows Settings → Apps → Drag Group Helper → Uninstall. Your Spaces, extensions and browser data remain untouched.

If Setup replaced an older portable registration, its path is saved for uninstall. The old folder is kept. If its manifest still exists, uninstall restores that registration; otherwise it removes only this helper's registration. Another installation's registration is always left alone.

If the status is not Ready

Check that .NET 10 Desktop Runtime x64 is installed, pause the other Drag Group edition, reload the extension and check its status. Setup verifies its files and Chrome registration; only Chrome can confirm the live connection.
