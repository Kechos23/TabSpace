# Security policy

Supported public versions are the current TabSpace, standalone Drag Group and shared helper installer releases. Security fixes are distributed through the release pages; unpacked installations need manual updates.

Report a suspected vulnerability using [GitHub private vulnerability reporting](https://github.com/Kechos23/TabSpace/security/advisories/new). Please provide the affected version, minimal reproduction and expected impact. Keep credentials, personal browsing data and backups out of public issues.

The technical [security model](docs/SECURITY.md), [privacy statement](docs/PRIVACY.md) and [known limitations](docs/KNOWN_LIMITATIONS.md) describe the current boundaries. A passing automated suite is not a guarantee that every environment or adversarial input has been tested.
